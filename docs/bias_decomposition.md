# Bias decomposition

For each paired AF/DF workload, the pipeline records signed and absolute policy gaps for loss, throughput, waiting, sojourn, and occupancy. Their deterministic midpoint is compared with the exact reference. The ordering half-width is half the AF/DF gap; ratios use null when their denominator is zero. The analysis also records whether the exact reference lies in the deterministic interval.

Arrival and accepted-service quantization errors are signed and summarized with absolute means, quantiles, extrema, zero/shortened/lengthened fractions, and accumulated error. Correlations are descriptive associations, not causal effects.
