# Interpretation cautions

Relative errors are unstable when exact packet loss is near zero. Waiting metrics condition on accepted jobs and can show survivor bias. Random ordering adds tie-order variance. Capacity includes service, and these simulations concern process-level timestamp representation, not physical network timing. A process crash and power-loss durability are unrelated to this study.
# Phase II interpretation update

Separate midpoint quantization bias from AF/DF ordering half-width and from insertion scheduler dependence. Quantization-error correlations and predictor regressions are associations, not causal estimates. Non-M/M workloads have no theory error and use exact simulation as their reference.
